# 🎓 StudentHub Portal

A modern and responsive university student portal designed to provide students with a centralized platform for accessing academic information, university services, events, announcements, and student resources.

---

## 📌 About The Project

StudentHub is a web-based university portal created to make student life easier by bringing important academic and campus-related services together in one place.

The portal provides a simple, clean, and responsive interface where students can access information such as events, academic resources, profiles, feedback, announcements, and other university services.

The project focuses on creating a user-friendly digital environment that can be accessed from desktops, laptops, tablets, and mobile devices.
